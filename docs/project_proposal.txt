1. Problem / Project Goal Definition

Problem — For a given audio recording with multiple speakers, automatically generate a transcription with speaker labels (who spoke when and what was said).

System Input — Meeting audio recording (WAV format)
Expected Output — Transcript with timestamps and speaker identities in two formats:
1. Textual — for displaying results
2. JSON — for evaluation and further processing
[00:00:12 - 00:00:15] Speaker_A: I think we need to change
the approach.
[00:00:15 - 00:00:20] Speaker_B: I agree, but first we must
analyze the data.

The project goal is to systematically compare three speaker diarization modes:
1. Unknown number of speakers — automatic discovery of speaker count via clustering (AHC)
2. Known number of speakers — clustering with a fixed number of clusters
3. Reference-embedding-based identification — direct classification using cosine similarity with reference speaker embeddings

2. Motivation for Solving the Problem

Automatic transcription with speaker identification is a key technology for numerous practical applications:
- Meeting transcription — Automatic note-taking of who said what in business meetings, without manual annotation
- Call center analytics — Identifying agents and clients in conversations for service quality analysis
- Media content indexing — Searching archives by speaker (e.g., "find all statements by person X")
- Assistive technologies — Real-time transcription for deaf and hard-of-hearing individuals with speaker identification
- Forensic analysis — Speaker identification in audio recordings for legal purposes

Current commercial systems (e.g., Google Speech-to-Text, Azure Speech) use generic diarization pipelines that are not specifically optimized for meeting scenarios. This project explores whether speaker embedding-based approaches (ECAPA-TDNN) with direct classification can surpass traditional clustering methods under realistic conditions, which would have direct implications for the design of production systems.

3. Relevant Literature

[1] Radford, A., Kim, J.W., Xu, T., Brockman, G., McLeavey, C., Sutskever, I. - arXiv (2022) Robust Speech Recognition via Large-Scale Weak Supervision.
https://arxiv.org/pdf/2212.04356.pdf
1. Paper Objective: Development of a universal ASR model that works robustly across different accents, background noise, and technical jargon without fine-tuning on a specific domain. The goal was to show that massive weakly supervised datasets can replace manually annotated training data for ASR.
2. Methodology: Transformer encoder-decoder architecture (up to 1.5B parameters). Input: mel-spectrogram features (80-dimensional). Output: text transcription with utterance-level timestamps (not word-level). Training on 680,000 hours of multilingual audio material collected via weak supervision from the internet. Uses multitask format with special tokens for language, task (transcription/translation), and timestamps.
3. Dataset: 680,000 hours of audio data from various sources (YouTube, podcasts, etc.), 100+ languages. Models vary from 39M (tiny) to 1.5B (large) parameters. The dataset is imbalanced, with English dominating at around 125,000 hours of translations and transcriptions.
4. Evaluation: Standard ASR benchmark sets: LibriSpeech (test-clean, test-other), Common Voice, CHiME-4, TED-LIUM, VoxPopuli. Metric: WER (Word Error Rate). Zero-shot evaluation without fine-tuning on target sets.
5. Results: Whisper large-v2 achieves WER of ~2.3% on LibriSpeech test-clean and ~5.4% on test-other, which is state-of-the-art without fine-tuning. On CHiME-4 (meetings with noise) it achieves WER of ~8.5%, significantly better than previous models that required domain-specific training.
6. Conclusion: We will use Whisper as the ASR component of our pipeline. Its timestamps (though at utterance level) are sufficient for initial alignment with diarization. Our work differs because Whisper does not solve diarization (it will be used exclusively for transcription), while speaker identification is handled through a parallel branch with speaker embeddings. Additionally, our pipeline operates on the AMI Meeting Corpus (specific meeting domain), whereas Whisper was evaluated on general ASR benchmarks.
7. Limitations: Whisper does not distinguish speakers in multi-speaker recordings. Timestamps are at the utterance level (±500ms), not word-level, which complicates precise alignment with diarization. It is not optimized for overlapping speech.

[2] Desplanques, B., Thienpondt, J., Demuynck, K. - Interspeech (2020) ECAPA-TDNN: Emphasized Channel Attention, Propagation and Aggregation in TDNN Based Speaker Verification.
https://www.isca-archive.org/interspeech_2020/desplanques20_interspeech.pdf
1. Paper Objective: Improving speaker verification through a new TDNN architecture that more efficiently models temporal characteristics and uses channel-level attention mechanisms for better speaker discrimination.
2. Methodology: ECAPA-TDNN uses three key innovations: (1) Res2Net blocks for multi-scale temporal extraction within each layer, (2) Squeeze-and-Excitation (SE) blocks for channel attention — automatic learning of each channel's importance, (3) Multi-layer feature aggregation — combining frame-level and segment-level statistics. Embedding dimension: 192 or 512. PLDA scoring is used for verification. The model has ~6.2M parameters.
3. Dataset: VoxCeleb1 + VoxCeleb2 (~7,000 speakers, ~1.2M utterances). VoxCeleb1: 1,251 speakers, ~150K utterances. VoxCeleb2: 5,994 speakers, ~1M utterances. Evaluation on VoxCeleb1-O (original) test set — 40 speakers, ~37K utterance pairs. The dataset is imbalanced — some speakers have significantly more utterances.
4. Evaluation: Metric: EER (Equal Error Rate) and minDCF on VoxCeleb1-O. Comparison with x-vector and ResNet-based models. Without data augmentation for baseline, with augmentation (music, noise, reverberation) for enhanced version.
5. Results: ECAPA-TDNN achieves EER of ~0.80% on VoxCeleb1-O (with augmentation), significantly better than x-vector (~1.50%) with fewer parameters (~6.2M vs ~7M). With augmentation, EER drops to ~0.63%. It is shown that SE attention and multi-scale feature aggregation contribute equally to performance.
6. Conclusion: We will use the pretrained ECAPA-TDNN model (via SpeechBrain: speechbrain/spkrec-ecapa-voxceleb) to extract 512-dimensional speaker embeddings for each audio segment. Our work differs because ECAPA-TDNN in the original paper serves for speaker verification (whether two samples are from the same speaker), while we use embeddings for diarization — grouping segments by speaker (clustering) or direct classification (cosine similarity with reference samples). Also, our model is trained on VoxCeleb (YouTube interviews), and we apply it to the AMI Meeting Corpus (meetings with distant microphones), which tests cross-domain generalization.
7. Limitations: The model is trained on cleaner audio (YouTube interviews), which may cause domain mismatch for AMI SDM configuration (reverberation, noise, overlapping speech). The question is how much embedding quality degrades under noisy and echoey conditions. The original paper does not evaluate diarization or overlapping speech.

[3] Bredin, H. - Interspeech (2023) pyannote.audio 2.1 Speaker Diarization Pipeline: Principle, Benchmark, and Recipe.
https://www.isca-archive.org/interspeech_2023/bredin23_interspeech.pdf
1. Paper Objective: Presenting significant improvements to the pyannote.audio diarization pipeline (version 2.1) that combines segmentation, neural speaker embedding, and agglomerative clustering, with recipes for adaptation to user datasets.
2. Methodology: Three phases: (1) Speaker segmentation — applied to short sliding windows (5s with 500ms step, significantly shorter than previous 30s windows), which reduces the upper bound on speaker count and enables denser embeddings, (2) Neural speaker embedding — extraction of local speaker embeddings for each detected segment, (3) Global agglomerative clustering — linking local labels into global identities. Overlapping windows act as test-time augmentation.
3. Dataset: The following datasets are benchmarked: DIHARD III, VoxConverse, AMI Meeting Corpus, AISHELL-4, Ego4D, REPERE, and This American Life.
4. Evaluation: Metric is DER (Diarization Error Rate). Comparison of out-of-the-box performance with and without fine-tuning on the target dataset.
5. Results: Out-of-the-box DER varies from ~8% (REPERE) to ~64% (Ego4D validation). Fine-tuning on the target dataset consistently leads to significant improvements.
6. Conclusion: We will use pyannote.audio 2.1 as the basis for classical diarization (Scenario 1 and 2 clustering). Its segmentation model will be used for speech region detection. Our work differs in two key aspects: we add Scenario 3 — reference-embedding-based identification (classification instead of clustering), and systematically compare all three modes on both IHM and SDM configurations, while the pyannote paper gives out-of-the-box results without direct comparison between microphone configurations. Additionally, our pipeline integrates ASR (Whisper) with diarization.
7. Limitations: The pipeline uses clustering as the final stage — it does not use available reference speaker samples when they are known. It does not integrate an ASR component. Out-of-the-box performance varies significantly between datasets (8–64% DER), indicating a need for fine-tuning.

[4] Bain, M., Huh, J., Han, T., Zisserman, A. - Interspeech (2023) WhisperX: Time-Accurate Speech Transcription of Long-Form Audio.
https://www.isca-archive.org/interspeech_2023/bain23_interspeech.pdf
1. Paper Objective: Addressing three key limitations of Whisper when transcribing long-form audio: (1) drift, hallucinations, and repetitiveness when using a sliding window approach, (2) inaccurate utterance-level timestamps and lack of word-level timestamps, (3) inability to process in parallel due to sequential nature.
2. Methodology: Two key components: (1) VAD Cut & Merge — VAD detects speech regions, audio is cut into ~30s chunks with boundaries in silent regions (where VAD activity is minimal), enabling Whisper batch processing (~12× speedup), (2) Forced phoneme alignment — a wav2vec2.0 phoneme model is used for precise alignment of transcription with audio at word level. The system does not include diarization in the paper itself, but it was added subsequently in the GitHub implementation.
3. Dataset: AMI Meeting Corpus (IHM), Switchboard-1 Telephone Corpus (SWB) (about 2400 hours of phone conversations), TEDLIUM-3 (11 TED talks, each 20 minutes long), Kincaid46 (various YouTube videos). Audio varies from clean to noisy.
4. Evaluation: ASR: WER on long audio recordings. Timestamp accuracy: word segmentation error rate. Speed: real-time factor (RTF). Comparison with vanilla Whisper and other ASR systems.
5. Results: WhisperX demonstrates state-of-the-art performance on long-form transcription. The VAD Cut & Merge strategy improves transcription quality and enables ~12× speedup via batched inference. Forced alignment gives precise word-level timestamps.
6. Conclusion: From this paper we adopt two ideas: (a) VAD-based segmentation as a first step — cutting audio into speech regions before further processing, and (b) the forced alignment concept for more precise timestamps. Although the WhisperX paper does not cover diarization, the GitHub implementation uses pyannote.audio for speaker labeling — which is architecturally similar to our approach (ASR + diarization as parallel branches).
7. Limitations: The paper deals exclusively with ASR issues. Forced alignment requires a language-specific wav2vec2 model.

4. Dataset

An existing publicly available dataset is used: the AMI Meeting Corpus.
Reference and availability:
- Official website: https://groups.inf.ed.ac.uk/ami/corpus/
- The dataset is also available on HuggingFace:
  - edinburghcstr/ami
  - diarizers-community/ami

Target label: Speaker identity for each time segment (classification into 4 classes, one for each of the 4 meeting participants). Data distribution across classes is approximately uniform since each participant speaks for a similar amount of time.
Available attributes:
- Audio recordings (16kHz WAV) in two configurations: IHM (Individual Headset Microphones) and SDM (Single Distant Microphone)
- Ground truth transcriptions with word-level timestamps
- Ground truth speaker labels (who spoke when)
- Approximately 100 hours total (65h of "acted" meetings, 35h of real meetings)
- 4 speakers per meeting

5. Methodology
1. ASR Component: Whisper model for transcription with word-level timestamps.
2. VAD + Segmentation: pyannote.audio VAD model for detecting speech segments. Segments are split into ~1.5s clips for embedding extraction.
3. Speaker Embedding Extraction: ECAPA-TDNN model (trained on VoxCeleb) for extracting 512-dimensional embeddings for each segment.
4. Three diarization modes:
   - Scenario 1: Agglomerative Hierarchical Clustering (AHC) with automatic number of clusters determination. Post-hoc mapping to reference IDs.
   - Scenario 2: AHC with fixed k=4. Mapping to reference IDs.
   - Scenario 3: Direct classification — for each segment, cosine similarity is computed with reference embeddings of each speaker. The identity with highest similarity is assigned.
5. ASR + Diarization Integration: Timestamps from Whisper are aligned with diarization segments. Final output is a transcript with speaker labels.
All three scenarios are run on both dataset variants (IHM and SDM), yielding a total of 6 experiments.

6. Evaluation Method
Evaluation procedure:
- Standard AMI train/test split (according to the official split) is used
- Evaluation on the test set (scenario meetings not used for parameter tuning)
- For Scenario 3 (reference identification), reference samples are extracted from the first 30 seconds of each speaker (enrollment period)
Evaluation Metrics:
1. DER (Diarization Error Rate) — primary metric for diarization:
   DER = (Missed Speech + False Alarm + Speaker Confusion) / Total Speech Duration
   - Collar: 0.25s (tolerance around boundaries)
   - Skip overlap: True (overlapping regions excluded for cleaner evaluation)
   - Implementation: pyannote.metrics
2. WER (Word Error Rate) — for evaluating ASR quality:
   WER = (Substitutions + Deletions + Insertions) / Total Number of Reference Words
   - Implementation: jiwer Python library
3. Speaker Identification Accuracy — for Scenario 3:
   Accuracy = Correctly Identified Segments / Total Segments
4. JER (Jaccard Error Rate) — alternative metric that gives equal weight to each speaker:
   JER = 1 − (Intersection / Union of reference and hypothesis segments)
Evaluation Hypotheses:
- Scenario 3 will show the smallest DER gap between IHM and SDM
- Scenario 1 will show the largest DER gap between IHM and SDM
- Scenario 2 will be between these two
